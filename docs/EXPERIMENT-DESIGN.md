# Experiment Design

Minimum READY requirements:

1. Explicit question  
2. Candidate / evidence basis  
3. Independent variable (registry)  
4. Dependent measure (feature/metric versioned)  
5. Controls  
6. Confounds  
7. Intervention  
8. Fork point  
9. Run count  
10. Replication criteria  
11. Stopping rule  
12. Analysis rule  
13. Claim boundary  

Missing required design data → `INVALID` or `NOT_COMPUTABLE` (if evidence unavailable).

Natural-language hypothesis is non-authoritative; machine variables and interventions are claim-bearing.
