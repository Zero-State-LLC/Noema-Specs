# Terminology

Canonical terms are singular nouns unless a contract says otherwise. Display copy may vary, but schemas and specifications use these meanings.

| Term | Definition |
| --- | --- |
| **Artifact** | Immutable, content-addressed runtime package emitted by the Phenomenon Compiler. |
| **Belief** | Mutable player or group interpretation. A belief is not world truth or evidence. |
| **Calibration** | Versioned procedure and result mapping instrument response to a reference. |
| **Capability** | Explicit permission to observe, construct, travel, analyze, or intervene. |
| **Capability Graph** | Versioned requirements graph that evaluates capability state. |
| **Canonical truth** | Private authoritative world state and law resolution. |
| **Condition** | Recorded environmental or procedural context for an observation or trial. |
| **Confound** | Variable offering a plausible alternative explanation for a result. |
| **Contradiction** | Incompatibility among eligible observations, predictions, or claims requiring resolution. |
| **Derived observation** | Observation produced by a declared transformation of parent records. |
| **Evidence** | Provenance-bearing relationship between eligible records and a claim or requirement. Evidence is not a generic collectible. |
| **Evidence Ledger** | Append-only lineage of validated evidence records and status changes. |
| **Experiment** | Preregistered plan and one or more trials designed to distinguish predictions. |
| **Frontier** | Reachable boundary of unresolved phenomena and not-yet-demonstrated capabilities. |
| **Frontier Director** | Policy system that ranks and schedules frontier opportunities without changing truth. |
| **Hypothesis** | Falsifiable explanatory or predictive model authored before assessment. |
| **Instrument** | Versioned observation mechanism with response, calibration, noise, limits, and cost. |
| **Intervention** | Authorized action intended to change canonical world state. |
| **Law** | Reusable canonical causal rule in the World Model. |
| **Notebook** | Player-facing workspace for observations, beliefs, models, plans, and citations. |
| **Observation** | Immutable instrument-mediated measurement with conditions, uncertainty, and provenance. |
| **Observatory** | Subsystem that creates observations from eligible world signals through instruments. |
| **Phenomenon** | Encounterable manifestation of laws under particular entities, conditions, and observability. |
| **Phenomena Lab** | Internal authoring, simulation, review, and release workspace. |
| **Phenomenon Compiler** | Deterministic pipeline turning sources into validated artifacts. |
| **Prediction** | Precommitted expected outcome, range, or ordering under stated conditions. |
| **Provenance** | Trace of origin, actors, versions, conditions, transformations, and parent records. |
| **Replication** | New trial that cites an earlier plan and tests repeatability under declared conditions. |
| **Signal** | World output eligible for mediation by an instrument. It is not directly player-visible truth. |
| **Trial** | One execution of a preregistered experiment plan. |
| **Uncertainty** | Quantified or categorized limit on a value or inference, including measurement, stochastic, and epistemic forms. |
| **World Model** | Authoritative deterministic simulation of canonical state and laws. |

## Avoid

- Do not use “fact” for a player claim or single observation.
- Do not use “proof” when evidence only supports or challenges a hypothesis.
- Do not use “random” without naming the seeded stream or intended nondeterminism.
- Do not call telemetry “evidence.”
- Do not use “unlock” for temporary discovery UI unless capability authority changes.
