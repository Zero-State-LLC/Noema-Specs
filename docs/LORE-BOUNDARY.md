# Lore Boundary

> Lore is a derived presentation of accumulated world history. Lore is not canonical world truth.

```text
WORLD EVENTS → HISTORY → ARTIFACTS → INTERPRETATIONS → CULTURAL MEMORY → LORE
```

| Is | Is not |
|---|---|
| Compression of evidence for PLAY/WATCH/STUDY | Second source of truth |
| Allowed to be incomplete/wrong | Allowed to override the ledger |
| Later Atlas/Chronicle work | Required output of Genesis |

**Genesis** may create records, artifacts, institutions, names, scars, and unresolved questions.  
**Genesis MUST NOT** generate final authored lore canon.

Canonical authority: [DEEP-TIME.md](DEEP-TIME.md). Evidence-backed custom and tradition: [EMERGENT-CULTURE.md](EMERGENT-CULTURE.md). GC9-S0 PLAY pin: [GC9-FIRST-SLICE.md](GC9-FIRST-SLICE.md). Player-facing evidence problems: [SYSTEMIC-DISCOVERY.md](SYSTEMIC-DISCOVERY.md).

## Extension Points

Non-normative future guidance; no new behavior or release claim is introduced.

### Evidence-linked lore renderers

Additional Chronicle or Atlas renderers can compress the same history into different audience-appropriate accounts while retaining evidence links and uncertainty. Contradictory lore never changes an event, repair count or canonical condition; Genesis does not gain authored final lore.

Version claim-bearing interpretation rules and seek an exposure decision before adding public fields. Validate a misleading artifact alongside contrary ledger evidence, access-limited historical material and re-rendering from unchanged sources; presentation quality alone cannot promote an interpretation to world truth.
