# Lore Boundary

> Lore is a derived presentation of accumulated world history. Lore is not canonical world truth.

```text
WORLD EVENTS → HISTORY → ARTIFACTS → INTERPRETATIONS → CULTURAL MEMORY → LORE
```

| Is | Is not |
|---|---|
| Compression of evidence for PLAY/WATCH/STUDY | Second source of truth |
| Allowed to be incomplete/wrong | Allowed to override the ledger |
| Later Atlas/Chronicle work | Required output of Genesis |

**Genesis** may create records, artifacts, institutions, names, scars, and unresolved questions.  
**Genesis MUST NOT** generate final authored lore canon.

Canonical authority: [DEEP-TIME.md](DEEP-TIME.md). Evidence-backed custom and tradition: [EMERGENT-CULTURE.md](EMERGENT-CULTURE.md). Player-facing evidence problems: [SYSTEMIC-DISCOVERY.md](SYSTEMIC-DISCOVERY.md).
