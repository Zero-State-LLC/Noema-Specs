# Progression

## Principle

No universal XP or single score. Plural progression surfaces.

## Surfaces

| Surface | Growth | Decline | Strategic benefit |
|---------|--------|---------|-------------------|
| Economic capacity | Production + trade | Loss, consumption, seizure | Sustained action |
| Production capacity | Infrastructure + nodes | Degradation, sabotage | Throughput |
| Storage capacity | Bays + holdings | Damage, overflow | Buffer against shocks |
| Infrastructure network | Build / repair / control | Condition loss | Modifiers and presence |
| Territorial reach | Presence + control | Contested loss | Options and security |
| Knowledge | Exploration + records | Loss of access | Information advantage |
| Influence | Org activity + success | Crime, failure, expulsion | Authority and negotiation |
| Organization strength | Members + coherence | Fracture | Coordination |
| Relationships | Agreements + trust | Betrayal, crime | Lower friction |
| Discoveries | Exploration | — | New options |
| Historical achievements | Notable events | — | Narrative weight and soft power |

Progression creates new possibilities and tradeoffs, not merely larger numbers.

## Forbidden

- Single victory score or XP ladder as the primary goal
- Research metrics (capability confidence, anomaly scores) as progression surfaces
