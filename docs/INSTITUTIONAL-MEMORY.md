# Institutional Memory

Memory held by persistent institutions may include rules, records, agreements, maps, member history, known threats, resource practices, and historical interpretations.

Separate:

```text
institution remembers X
```

from:

```text
X is objectively true
```

Institutional memory is historical evidence of class `INSTITUTION_ARCHIVE`. It may be incomplete or wrong. Canonical ledger remains independent.

Without custodians, memory may fragment under [Historical Decay](HISTORICAL-DECAY.md); records are not hard-deleted.

Player↔Player and Institution↔Player **relationship** memory is [Social Memory](SOCIAL-MEMORY.md). That is not this archive layer. Institution→Player edges used for office eligibility must not leak hidden facts.
