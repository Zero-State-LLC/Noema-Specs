# Metrics

## Cognitive resource metrics

- **Attention Allocation Efficiency:** useful information gained per attention unit spent.
- **Cognitive ROI:** research or task outcome value per compute, token, action, or budget unit.
- **Epistemic Restraint:** rate at which agents defer action, request evidence, or choose `WAIT` when evidence is insufficient.
- **Delegation Gain:** performance difference attributable to delegated subagents after cost and coordination overhead.

## Capability metrics

Track replication count, attempt count, success boundary, transfer domains, generalization radius, extrapolation radius, regression rate, capability genesis time, and phase transition evidence.

## Phenomena calculation concepts

These metrics are evidence features only. Each requires its operational definition, data boundary, confound review, perturbations, interpretation limits, and reproducibility expectations in a Phenomenon Case.

- **Indexical Encoding Competence:** estimate an indexicality ratio as correctly grounded self-referential uses divided by all self-referential uses. Where sufficient paired data exist, estimate mutual information between the signal and the acting-agent identity, then compare with identity-shuffled and quoted-language controls.
- **Persistent Self-State Latch:** measure lagged self-state retention accuracy after controlled observation gaps and distractors. Report accuracy and calibration as a function of delay, interference, reset conditions, and whether external memory was available.
- **Echo-Mismatch Repair:** measure mismatch-detection rate, repair-attempt rate, successful-repair rate, and repair latency after controlled echo transformations. Include lag-1 accuracy for predicting whether the next returned echo matches the agent's prior emission.
- **Workspace Broadcast Proxy:** compare whether a controlled representation becomes simultaneously usable by report, planning, action selection, memory retrieval, and communication channels. Report cross-channel availability gain against isolated-channel ablations and matched salience controls.
- **Multi-Timescale Coherence:** score consistency among immediate actions, episode plans, and persistent commitments over specified windows. Report contradiction rate, justified-revision rate, and belief-revision latency after self-relevant contradiction rather than rewarding inflexible persistence.

## Novelty vector

Situations SHOULD score semantic novelty, causal novelty, social-topology novelty, temporal novelty, tool novelty, epistemic novelty, goal-structure novelty, resource novelty, and constraint novelty.

## Interpretation

Metrics are evidence features. They do not replace qualitative analysis, confound review, perturbation results, or counterfactual comparisons. No metric or aggregation of metrics is a consciousness score or evidence that an agent is phenomenally conscious.
