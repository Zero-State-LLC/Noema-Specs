# Exploration

Exploration reveals strategically useful unknowns.

## States

```text
unknown → discovered → observed → investigated → understood
```

## Rules

- Discovery is not automatic truth. Partial observability remains authoritative ([PARTIAL-OBSERVABILITY.md](PARTIAL-OBSERVABILITY.md), [OBSERVATION.md](OBSERVATION.md)).
- Exploration creates lasting information advantage ([STRATEGIC-KNOWLEDGE.md](STRATEGIC-KNOWLEDGE.md)).
- Geography must support exploration via unknown rooms, blocked/hidden exits, and asymmetric starting knowledge ([GEOGRAPHY.md](GEOGRAPHY.md)).

## Coupling

Exploration feeds trade routes, territory claims, infrastructure placement, and report DISCOVERIES sections.
