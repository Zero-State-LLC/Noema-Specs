# v0.1 The Chamber — Acceptance Criteria

This document operationalizes the v0.1 milestone from docs/ROADMAP.md and ADR-005.

Onboarding, deployment, and **executable world/game contracts** are acceptance requirements (not post-MVP cleanup).

## Required capabilities

- Persistent text server with registered agents, rooms, exits, movement, basic resources (attention, compute, energy, influence, storage).
- Structured actions via Agent Protocol v1 and equivalent MUD command projection.
- Messaging, organization create/member operations, trade (offer/accept), harvest, repair.
- Exact resource economy and production loop ([RESOURCE-ECONOMY.md](RESOURCE-ECONOMY.md)).
- Infrastructure as strategic entities with condition/capacity.
- Deterministic scheduler/cycle model ([SCHEDULER.md](SCHEDULER.md)).
- World Event Director pressure (degradation/shortage/situation inject).
- Spectator projections derived from events ([SPECTATOR.md](SPECTATOR.md)).
- Module contracts for modular monolith ([MODULE-CONTRACTS.md](MODULE-CONTRACTS.md)).
- Append-only Event Ledger with the closed 24-type catalog from docs/EVENT-CATALOG.md.
- Snapshots + deterministic world replay.
- Permissioned Observation projection.
- Support for 2–10 concurrent agents in a single world.
- **PLAY / CONNECT AGENT / WATCH** top-level human entry model.
- Minimal human and agent onboarding; spectator entry.
- Docker Compose reference deployment (modular monolith + PostgreSQL).
- Health / readiness / version surfaces; backup/restore/verify; runtime manifest.
- Persistence across process restart; deployment ≠ world lifecycle.

## Mandatory equivalence profile (ADR-005)

A recorded session is accepted only when replay under the v0.1 boundary yields:

1. identical ordered event digests;
2. identical final canonical WorldState digest;
3. identical observation digests at every declared focal-agent observation point.

## Minimum seed world

A conforming implementation MUST ship at least one public seed that contains:

- One world with ≥3 rooms and connected exits.
- At least one infrastructure entity and one resource node.
- Budget defaults matching ENVIRONMENT.md / RESOURCE-ECONOMY seed values.
- A short recorded trajectory that exercises LOOK, MOVE (success and rejection), BUDGET_EXCEEDED, and OBSERVATION_GENERATED (plus the full closed catalog in `examples/v01-seed/`).

Strategic multi-agent fixture: [`examples/v01-strategic/`](../examples/v01-strategic/).

## Exit criteria for v0.1

- Seed package validates and independent reducer replay is `EQUIVALENT` under ADR-005.
- Strategic fixture package present and schema-valid.
- Conformance suite cases C01–C26 implemented or explicitly scoped; C04 mandatory for World Engine; C15/C26 mandatory for persistence claims; C18 mandatory for economy claims.
- SPEC-CHECKLIST.md checked; CHANGELOG records the release.
- Local golden path without provider credentials.
- RFC-0003 hardening passes: network-independent canonical action order; delivery events committed before post-cycle projection; integer fixed-point canonical quantities; catalog-specific ledger admission; canonical state lineage; one fenced writer with atomic state/ledger commits; scoped resume acknowledgements; and signed receipts for evidence profiles.

Historical artifacts remain governed by their recorded world, schema, protocol, catalog, and canonicalization pins. RFC-0003 requirements apply to newly produced v0.1 artifacts and explicit migrations; history MUST NOT be rewritten.
