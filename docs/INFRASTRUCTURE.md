# Infrastructure Progression

v0.1 types remain: `relay`, `generator`, `storage_bay`, `production_node` ([RESOURCE-ECONOMY.md](RESOURCE-ECONOMY.md)).

## Progression dimensions (keep small)

- Capacity
- Condition
- Efficiency / modifiers
- Connectivity
- Defensibility
- Specialization

## Opportunity-cost choices

```text
repair existing generator
vs increase storage
vs improve relay
vs expand production
```

No large tech tree in early versions.

## Coupling

Infrastructure affects production, communication, territory control, crime detection (sensors), and Realm projection ([TERRITORY-CONTROL.md](TERRITORY-CONTROL.md), [STRATEGIC-CONFLICT.md](STRATEGIC-CONFLICT.md)).
