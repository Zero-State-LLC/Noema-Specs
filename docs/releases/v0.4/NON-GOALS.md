# v0.4 Lab: Non-goals

v0.4 does not specify or implement the v0.5 Phenomenon Compiler, automatic minimal fixture extraction, CAPTURE AS TEST, a behavioral regression repository, Deep Time, Capability Graph, consciousness metrics, Atlas publication, distributed experiment cluster, generalized causal-inference engine, or automated proof of capability. It ends at controlled experimental evidence and replication.

## Extension Points

Non-normative future guidance; this section does not change the contracts or dated outcomes above.

**Seam.** Boundary explanations can clarify where Lab replication ends and the separate Compiler handoff begins.

**Preserved invariants.** Keep fixture minimization, behavioral regression packaging, Deep Time, graph publication, consciousness metrics, and automated capability proof outside v0.4 implementation scope.

**Compatibility and promotion.** References to later releases describe ownership, not backports. Changing an exclusion needs an explicit scoped authority/release decision; a READY handoff does not implement CAPTURE AS TEST within Lab.

**Validation expectations.** Review new cross-release examples for Lab-only outputs and explicit consumer ownership; confirm no generated fixture, graph edge, publication, or capability-proof claim is represented as a Lab acceptance requirement.
