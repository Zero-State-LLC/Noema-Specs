# v0.7 LEARN: Migration

v0.7 adds **derived** behavior relationships.

MUST NOT rewrite Lab results, captured tests, regression results, or world history.

Eligible v0.5 artifacts may be projected into nodes/edges. If evidence is insufficient: **do not invent an edge**.

## Extension Points

Non-normative prospective guidance; this section neither changes release scope nor authorizes execution.

### LEARN projection migration

Future rebuilds can admit eligible v0.5 artifacts into derived nodes and edges while retaining source identities and the evidence needed for each relationship. Insufficient evidence produces no invented edge and never causes a Lab result, captured test or world event rewrite.

Pin the relationship catalog and projection version for each rebuild; changed edge semantics need the owning accepted contract and compatibility rule. Validate repeat rebuilds, duplicate inputs, unsupported relationships, missing evidence and prior-version interpretation, checking source digests remain unchanged. A rebuilt graph is not a new capability proof.
