# v0.6 Deep Time: Scope Delta

v0.6 foundation adds executable contracts for **historical persistence**: institutions, succession, historical artifacts, evidence, archaeology, reconstruction, institutional memory, cultural transmission foundations, world scars, and derived significance — so agents can leave structures that persist, decay, and are later inherited or investigated.

It also adds **simplified admin-only World Genesis**: a one-time create-world operation (seed + small profile + optional story seeds → valid Cycle 0), then permanent handoff to ordinary Chamber + Deep Time.

## Lore boundary

Lore is derived presentation, not a second source of truth. Genesis must not produce final lore.

## In scope

- Deep Time model layers and identity continuity classes
- Institution lifecycle and succession records
- Historical artifacts, integrity, decay (evidence only)
- Historical claims + conflicting claims
- Archaeology and reconstruction without narrative invention
- Historical names (canonical IDs immutable)
- World scars and inheritance foundations
- PLAY/WATCH/STUDY progressive disclosure for history
- **Admin-only Genesis** (3 profiles, closed story seeds, Cycle 0 result, preview/activate)

## Complexity rule

> Prefer the smallest architecture that preserves the intended behavior.

## Out of scope (this foundation)

Full markets, constitutional government, religion sim, procedural lore engine, full semantic evolution, runtime Deep Time engine, Genesis service/workers/APIs, player/agent Genesis controls, long-running prehistory simulation. See [NON-GOALS](NON-GOALS.md).

## Extension Points

Non-normative prospective guidance; this section neither changes release scope nor authorizes execution.

### Deep Time foundation coverage

Extend evidence maps for institutions, artifacts, scars and reconstruction within the foundation rather than silently promoting full markets, religion simulation or procedural lore. Admin-only preview/activate remains a one-time Cycle 0 boundary, not Player control or a long-running prehistory service.

Later accepted slices must be identified by their own versions and evidence rather than backdated into this scope delta. Validate lineage continuity, conflicting historical claims, access-limited archaeology and Genesis preview/activation compatibility against the owning authorities; scope prose alone establishes no hosted runtime status.
