# v0.6 Deep Time: Non-Goals

Do **not** implement in this repository:

- runtime Deep Time engine
- full market simulator / constitutional government / legal / religion systems
- procedural lore engine or LLM story generator
- full semantic-evolution engine (foundation only)
- Capability Graph / Atlas publication
- frontend, database, service workers
- silent event-catalog expansion without RFC
- authored lore canon overriding world history
- Genesis service / workers / scheduler / database / public player or agent APIs
- complex Genesis actors, large historical populations, long-running prehistory simulation
- story-seed constraint solver or natural-language seed compiler
- player-facing Genesis configuration controls

## Extension Points

Non-normative future guidance; no behavior is introduced by this section.

Future release planning may attach rationale and successor-authority links to these exclusions without authorizing implementation in this repository. In particular, semantic foundations do not authorize a lore generator, research publication, or a Genesis service, and historical claims cannot override canonical evidence. A proposed scope change requires its own Accepted RFC and explicit schema/event/version and consumer-compatibility review before promotion; it cannot enter through an example or extension note. Validate resulting documentation and fixtures for unchanged event catalogs, no public Genesis configuration surface, no story-seed solver assumptions, and no claim that specs alone supply a runtime engine. Preserve the current exclusions when adding a future-release pointer.
