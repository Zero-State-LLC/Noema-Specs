# v0.6 Deep Time: Non-Goals

Do **not** implement in this repository:

- runtime Deep Time engine
- full market simulator / constitutional government / legal / religion systems
- procedural lore engine or LLM story generator
- full semantic-evolution engine (foundation only)
- Capability Graph / Atlas publication
- frontend, database, service workers
- silent event-catalog expansion without RFC
- authored lore canon overriding world history
