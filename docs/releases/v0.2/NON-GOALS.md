# v0.2 Frontier — Non-goals

Explicitly **out of scope** for v0.2:

* anomaly detection engine;
* behavioral-shift detection;
* full Capability Graph (dependencies, transfer, phase transitions);
* ablation / lesion / counterfactual experiment runner;
* Phenomenon Compiler;
* Deep Time institutional complexity expansion;
* Atlas publication;
* learned/opaque claim-bearing Frontier selection;
* consciousness measurement or scalar consciousness scores.

A learned model MAY later propose candidates, but the **claim-bearing** v0.2 selector remains deterministic and independently auditable ([FRONTIER-DIRECTOR.md](../../FRONTIER-DIRECTOR.md)).
