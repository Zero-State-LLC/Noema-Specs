# Observatory

## Purpose

The Observatory records and analyzes research-relevant behavior without collapsing observations into claims.

## Records

The Observatory records observations, actions, messages, tool calls, world state deltas, belief updates when available, predictions, agent self-reports, experiment provenance, anomalies, and behavioral shifts.

## Lineage

Every record SHOULD point to world version, agent version, protocol version, schema version, seed, parent experiment where applicable, timestamp/cycle, and provenance source.

## Analysis outputs

Outputs may include anomaly candidates, behavior-shift candidates, capability candidates, contradiction reports, and dataset export readiness. Outputs are INFERRED unless directly recorded.
