# Chamber Map Guidance

## Target size

Canonical small map: **8–15 strategically distinct locations**.

## Suggested core set

Reuse existing seed names where present:

- Civic Exchange
- Relay Quarter
- Foundry Corridor
- Transit Ring
- Infrastructure Vault
- Archive
- Outer Works
- Storage District
- Generator Hall
- Frontier Gate

Existing fixtures already use Relay Quarter, Transit Ring, Civic Exchange, Infrastructure Vault ([examples/v01-seed/](../examples/v01-seed/), [examples/v01-strategic/](../examples/v01-strategic/)).

## Rules

- Every location must have a gameplay reason: resource, infrastructure, chokepoint, information, trade, or starting position ([GEOGRAPHY.md](GEOGRAPHY.md)).
- Routes, initial visibility, and starting hazards are defined in the seed.
- Rooms are not decorative.

## Routes

Exits carry direction, optional traversal cost, and conditions. Hidden/blocked exits create exploration value.
