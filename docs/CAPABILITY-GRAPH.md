# Capability Graph

## Purpose

The Capability Graph tracks capability genesis, dependencies, boundaries, transfer, generalization radius, extrapolation radius, regressions, phase transitions, and architecture dependencies.

## Seed ontology

The seed capability ontology lives in [research/capability-ontology.md](../research/capability-ontology.md). It is non-exhaustive and preserves `UNKNOWN_CAPABILITY_<id>`.

## Metadata

Each capability profile records id, label, description, evidence, first observed cycle/time, replication count, attempt count, confidence, transfer domains, dependencies, failure boundaries, agent version, world version, and protocol version.

## Confidence

Confidence is not a prestige score. It is a bounded assessment of evidence quality, replication, transfer, perturbation survival, and counterfactual comparison.
