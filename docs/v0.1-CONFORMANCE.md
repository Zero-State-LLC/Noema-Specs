## Implementation requirements

1. Schema-validate every case against `conformance-case.schema.json`.
2. Execute steps against fixtures.
3. Result document: `case_id`, `status` PASS|FAIL|SKIP|NOT_COMPUTABLE, digests when world-involved.
4. C04 non-skippable for World Engine claims; C15/C26 for persistence; C18 for economy claims.
5. C01–C17 MUST NOT be weakened.

## Pass criteria

All twenty-six cases PASS, or documented SKIP only when surface is out of build scope **and** boundary cases (C04, C10, C15/C26 as applicable) still hold.
