# v0.4 Lab evidence package

This retained research-side package tests a candidate coordination pattern through baseline, sham control, external ablation, perturbation, replication, and bounded version comparison. `experiment.json` is the immutable design, `experiment-plan.json` is its explicit DAG, `experiment-fork.json` proves isolated lineage, and `lab-result*.json` preserve supporting and null evidence.

`counterfactual.json` removes exactly one contradictory resource report at `AFTER_OBSERVATION` while holding declared variables fixed. `intervention-lesion-not-computable.json` is schema-only evidence that an undeclared internal lesion cannot execute. No file is a production-world mutation or a v0.5 regression fixture.
