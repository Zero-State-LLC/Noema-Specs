## Problem
RFC-0002 defines CRIME_DETECTED (detection, not guilt) and requires witness/sensor/investigation/self-report. Producer side (how play generates detections, delays, graduated effects, interaction with contestation/social memory) remains PARTIAL.

## Proposed Change (high level)
- Bounded extension note/section in STRATEGIC-CONFLICT.md (already partially done 2026-08-27): witness/sensor/investigation/self-report flows, delayed revelation (per hotspot models), ties to existing events.
- No new events. Reuses CRIME_DETECTED + ENTITY_* / contest.
- Fixtures for producer paths; integration with GC3 public descriptors and Deep Time.
- Formal verification angles (Cops/Robbers synthesis) optional.
