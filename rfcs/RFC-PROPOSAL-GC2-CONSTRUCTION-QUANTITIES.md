**Proposed:**
- First-world generalized `BUILD` / construction uses closed, versioned quantity tables per operation + constructible class (not free-form or runtime-chosen).
- Tables versioned in construction catalog (or equivalent authoritative surface).
- Existing GC2-S0 pins (v0.1 infrastructure classes via CONSTRUCT/DISMANTLE on ENTITY_*) remain unchanged.
- Ties to RESOURCE-ECONOMY budgets, Deep Time attribution of built structures, and owner/steward split (see B2b).
- No player-chosen costs; no runtime free-form entity generation.

**Scope / Boundaries:** Extends CONSTRUCTION.md authority only. No changes to ACTION-CONTRACTS, event catalog, or S0 pins. No new verbs. Research input + future RFC candidate. Smallest viable unit for B2a.
